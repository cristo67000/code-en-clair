# Langages et programmation.

@ variable
cat: langage
nom: Variable
alias: affectation, assignation, let, var, déclaration, declare, assign, identifiant de variable
fr: Nom qui désigne une valeur gardée en mémoire et pouvant changer au fil du programme. On la déclare, on lui donne une valeur (l'affectation), puis on la relit ou on la modifie par son nom.
en: A name that designates a value kept in memory and able to change as the program runs. You declare it, give it a value (assignment), then read or change it by its name.
ex: js
| let score = 0;
| score = score + 10;
| console.log(score);
ex-fr: Déclarer score à 0, y ajouter 10, puis afficher 10.
ex-en: Declare score as 0, add 10 to it, then print 10.
voir: constante, type, portee, mutabilite

@ constante
cat: langage
nom: Constante
nom-en: constant
alias: const, constant, final, readonly, valeur fixe, immutable binding
fr: Nom lié à une valeur qui ne changera plus après sa définition. Déclarer ce qui ne doit pas changer (const en JavaScript, final en Java) protège d'une modification par erreur et rend le code plus lisible.
en: A name bound to a value that will no longer change after its definition. Declaring what must not change (const in JavaScript, final in Java) protects against accidental modification and makes code more readable.
ex: js
| const TVA = 0.2;
| TVA = 0.3;
ex-fr: La deuxième ligne provoque une erreur : on ne peut pas réaffecter une constante.
ex-en: The second line throws an error: a constant cannot be reassigned.
attention-fr: const empêche de réaffecter le nom, pas de modifier un objet ou un tableau qu'il désigne : on peut toujours y ajouter des éléments.
attention-en: const prevents reassigning the name, not modifying an object or array it designates: you can still add elements to it.
voir: variable, mutabilite, type

@ type
cat: langage
nom: Type
nom-en: data type
alias: type de données, typage, typage statique, typage dynamique, static typing, dynamic typing, typescript, cast, conversion de type, coercion
fr: Catégorie d'une valeur, qui détermine ce qu'on peut en faire : nombre, chaîne, booléen, tableau, objet. Un langage à typage statique vérifie les types avant l'exécution (Java, TypeScript) ; à typage dynamique, pendant l'exécution (Python, JavaScript).
en: The category of a value, which determines what can be done with it: number, string, boolean, array, object. A statically typed language checks types before running (Java, TypeScript); a dynamically typed one, while running (Python, JavaScript).
ex: js
| typeof 42
| typeof 'texte'
| '5' + 1
| '5' * 2
ex-fr: number, string ; puis « 51 » (le nombre est converti en texte) et 10 (le texte est converti en nombre) : la coercition de JavaScript.
ex-en: number, string; then “51” (the number is converted to text) and 10 (the text is converted to a number): JavaScript's coercion.
voir: variable, string, null, nombre-flottant

@ fonction
cat: langage
nom: Fonction
nom-en: function
alias: function, méthode, procédure, appel de fonction, fonction fléchée, arrow function, lambda, fonction anonyme, return, valeur de retour, subroutine
fr: Bloc de code nommé qui accomplit une tâche précise : on l'écrit une fois, on l'appelle autant de fois qu'on veut, en lui passant des valeurs (paramètres). Elle peut renvoyer un résultat avec return.
en: A named block of code that performs a specific task: you write it once, call it as many times as you want, passing it values (parameters). It can send a result back with return.
ex: js
| function carre(x) {
|   return x * x;
| }
| const cube = (x) => x * x * x;
| carre(4) + cube(2)
ex-fr: Une fonction classique, une fonction fléchée, puis leur usage : 16 + 8 = 24.
ex-en: A regular function, an arrow function, then their use: 16 + 8 = 24.
+fr: Une fonction est dite « pure » quand son résultat ne dépend que de ses paramètres et qu'elle ne modifie rien autour d'elle (pas d'effet de bord) : elle est plus facile à tester.
+en: A function is called “pure” when its result depends only on its parameters and it changes nothing around it (no side effects): it is easier to test.
voir: parametre, portee, callback, closure, recursion

@ parametre
cat: langage
nom: Paramètre et argument
nom-en: parameter and argument
alias: parameter, argument, arguments, paramètre par défaut, default parameter, rest parameter, paramètre nommé, kwargs, args
fr: Le paramètre est le nom que la fonction déclare pour recevoir une valeur ; l'argument est la valeur réelle qu'on lui passe à l'appel. Dans « function saluer(nom) » et « saluer('Zoé') », nom est le paramètre et 'Zoé' l'argument.
en: The parameter is the name the function declares to receive a value; the argument is the actual value passed at call time. In “function greet(name)” and “greet('Zoé')”, name is the parameter and 'Zoé' is the argument.
ex: js
| function saluer(nom, formule = 'Bonjour') {
|   return `${formule} ${nom}`;
| }
| saluer('Zoé')
| saluer('Zoé', 'Salut')
ex-fr: Un paramètre a une valeur par défaut : « Bonjour Zoé » puis « Salut Zoé ».
ex-en: A parameter has a default value: “Bonjour Zoé” then “Salut Zoé”.
voir: fonction, argument, portee

@ portee
cat: langage
nom: Portée
nom-en: scope
alias: scope, variable locale, variable globale, local, global, portée de bloc, block scope, hoisting, shadowing
fr: Zone du programme où un nom est visible et utilisable. Une variable déclarée dans une fonction ou un bloc est locale : invisible à l'extérieur. Une variable globale est visible partout, ce qui la rend risquée.
en: The area of a program where a name is visible and usable. A variable declared in a function or block is local: invisible outside. A global variable is visible everywhere, which makes it risky.
ex: js
| let a = 'globale';
| function f() {
|   let a = 'locale';
|   return a;
| }
| f() + ' / ' + a
ex-fr: La fonction a sa propre variable a : le résultat est « locale / globale ».
ex-en: The function has its own variable a: the result is “locale / globale”.
attention-fr: La portée de sw.js (service worker) est autre chose : ici, il s'agit de portée de noms de variables.
attention-en: The scope of sw.js (service worker) is something else: here we mean the scope of variable names.
voir: variable, closure, fonction
schema: langage-portee

@ closure
cat: langage
nom: Closure
nom-fr: fermeture
alias: fermeture, clôture, lexical scope, portée lexicale, fonction interne
fr: Fonction qui garde l'accès aux variables de l'endroit où elle a été créée, même quand ce dernier a fini de s'exécuter. C'est ce qui permet à une fonction de « se souvenir » d'un état privé.
en: A function that keeps access to the variables of the place where it was created, even after that place has finished running. It is what lets a function “remember” a private state.
ex: js
| function compteur() {
|   let n = 0;
|   return () => ++n;
| }
| const suivant = compteur();
| suivant(); suivant();
ex-fr: Chaque appel de suivant() augmente le n caché : il renvoie 1 puis 2, alors que compteur() est terminé.
ex-en: Each call of suivant() increments the hidden n: it returns 1 then 2, although compteur() has finished.
voir: portee, fonction, callback
schema: langage-closure

@ callback
cat: langage
nom: Callback
nom-fr: fonction de rappel
alias: fonction de rappel, rappel, handler, gestionnaire, hook function, continuation, callback hell
fr: Fonction qu'on passe en argument à une autre fonction pour qu'elle l'appelle plus tard, quand un événement survient ou quand une opération se termine (la fin d'un chargement, un clic, un délai écoulé).
en: A function passed as an argument to another function so that it calls it later, when an event occurs or an operation finishes (the end of a load, a click, a delay elapsed).
ex: js
| setTimeout(() => console.log('trois secondes plus tard'), 3000);
| [1, 2, 3].forEach((n) => console.log(n * 2));
ex-fr: Une fonction appelée après un délai ; une autre appelée pour chaque élément d'un tableau.
ex-en: A function called after a delay; another called for each element of an array.
attention-fr: Des callbacks imbriqués sur plusieurs niveaux deviennent illisibles (callback hell) : les promesses et async/await les remplacent.
attention-en: Callbacks nested over several levels become unreadable (callback hell): promises and async/await replace them.
voir: promesse, evenement, async-await, fonction
schema: langage-callback

@ promesse
cat: langage
nom: Promise
nom-fr: promesse
alias: promesse, promise, then, catch, finally, thenable, future, resolve, reject, pending, promise.all
fr: Objet qui représente le résultat futur d'une opération asynchrone : au départ « en attente » (pending), il finit soit tenu (fulfilled, avec une valeur), soit rompu (rejected, avec une erreur). On y enchaîne des traitements avec then et catch.
en: An object that represents the future result of an asynchronous operation: at first “pending”, it ends up either fulfilled (with a value) or rejected (with an error). Processing is chained onto it with then and catch.
ex: js
| fetch('/termes.json')
|   .then((r) => r.json())
|   .then((termes) => console.log(termes.length))
|   .catch((erreur) => console.error(erreur));
ex-fr: Télécharger un fichier, le lire en JSON, afficher le nombre d'éléments, et gérer toute erreur à la fin de la chaîne.
ex-en: Download a file, read it as JSON, print the number of items, and handle any error at the end of the chain.
voir: async-await, callback, fetch, event-loop
schema: langage-promesse

@ async-await
cat: langage
nom: async / await
alias: async, await, asynchrone, asynchronous, synchrone, synchronous, code asynchrone, non bloquant, non-blocking
fr: Syntaxe qui permet d'écrire du code asynchrone comme s'il était séquentiel : await suspend la fonction (déclarée async) jusqu'à ce qu'une promesse soit résolue, sans bloquer le reste du programme.
en: A syntax that lets you write asynchronous code as if it were sequential: await suspends the (async-declared) function until a promise resolves, without blocking the rest of the program.
ex: js
| async function charger() {
|   try {
|     const reponse = await fetch('/termes.json');
|     return await reponse.json();
|   } catch (erreur) {
|     console.error('Échec', erreur);
|   }
| }
ex-fr: Le même enchaînement que les promesses, mais lisible de haut en bas, avec try/catch pour les erreurs.
ex-en: The same chain as with promises, but readable from top to bottom, with try/catch for errors.
attention-fr: Asynchrone ne veut pas dire « en parallèle » : en JavaScript, le code reste sur un seul fil, mais il ne l'occupe pas pendant qu'il attend.
attention-en: Asynchronous does not mean “in parallel”: in JavaScript the code stays on a single thread, but does not occupy it while waiting.
voir: promesse, callback, event-loop, fetch

@ event-loop
cat: langage
nom: Event loop
nom-fr: boucle d'événements
alias: boucle d'événements, boucle événementielle, call stack, pile d'appels, task queue, file de tâches, microtask, macrotask, single thread
fr: Mécanisme qui permet à JavaScript, malgré son fil d'exécution unique, de gérer des opérations qui prennent du temps. Il attend que la pile d'appels soit vide, puis prend la tâche suivante en attente (un clic, un délai écoulé, une réponse réseau).
en: The mechanism that lets JavaScript, despite its single thread of execution, handle operations that take time. It waits for the call stack to be empty, then takes the next waiting task (a click, an elapsed delay, a network response).
+fr: Un calcul long qui n'en finit pas bloque cette boucle : la page se fige, car plus aucun clic n'est traité. On le confie à un Web Worker, ou on le découpe.
+en: A long-running computation blocks this loop: the page freezes, because no click is processed any more. It is handed to a Web Worker, or split up.
voir: callback, promesse, async-await, thread, web-worker
schema: langage-event-loop

@ thread
cat: langage
nom: Thread
nom-fr: fil d'exécution
alias: fil d'exécution, fil, multithreading, multi-thread, concurrence, concurrency, parallélisme, parallelism, mutex, race condition, deadlock
fr: Suite d'instructions qui s'exécute de façon indépendante à l'intérieur d'un processus. Plusieurs threads partagent la même mémoire et peuvent avancer en même temps sur plusieurs cœurs, ce qui accélère les calculs mais introduit des risques de conflits.
en: A sequence of instructions that runs independently inside a process. Several threads share the same memory and can advance at the same time on several cores, which speeds up computation but introduces risks of conflicts.
+fr: Deux threads qui modifient la même donnée sans coordination créent une « condition de concurrence » (race condition) aux résultats imprévisibles. On l'évite avec des verrous (mutex) ou en partageant le moins possible.
+en: Two threads modifying the same data without coordination create a “race condition” with unpredictable results. It is avoided with locks (mutexes) or by sharing as little as possible.
voir: processus, event-loop, web-worker, async-await

@ boucle
cat: langage
nom: Boucle
nom-en: loop
alias: loop, for, while, do while, foreach, itération, itérer, iteration, boucle infinie, infinite loop, break, continue
fr: Structure qui répète un bloc d'instructions : un nombre de fois connu (for), tant qu'une condition reste vraie (while), ou pour chaque élément d'une collection (for…of). break sort de la boucle, continue passe au tour suivant.
en: A structure that repeats a block of instructions: a known number of times (for), as long as a condition stays true (while), or for each element of a collection (for…of). break leaves the loop, continue skips to the next round.
ex: js
| for (let i = 1; i <= 3; i++) console.log(i);
| for (const langage of ['js', 'py']) console.log(langage);
| let n = 3;
| while (n > 0) n--;
ex-fr: Compter de 1 à 3 ; parcourir un tableau ; décrémenter jusqu'à zéro.
ex-en: Count from 1 to 3; run through an array; decrement down to zero.
attention-fr: Une condition d'arrêt qui n'est jamais atteinte produit une boucle infinie : le programme ne rend plus la main.
attention-en: A stop condition that is never reached produces an infinite loop: the program never gives control back.
voir: condition, tableau, recursion, algorithme
schema: langage-boucle

@ condition
cat: langage
nom: Condition
nom-en: conditional
alias: if, else, switch, booléen, boolean, opérateur ternaire, ternary, and or not, &&, ||, !, truthy, falsy, vrai faux
fr: Instruction qui exécute un bloc de code seulement si une expression est vraie (if), éventuellement un autre sinon (else). Les expressions se combinent avec ET (&&), OU (||) et NON (!).
en: An instruction that runs a block of code only if an expression is true (if), possibly another one otherwise (else). Expressions are combined with AND (&&), OR (||) and NOT (!).
ex: js
| const age = 17;
| if (age >= 18) {
|   console.log('majeur');
| } else {
|   console.log('mineur');
| }
| const statut = age >= 18 ? 'majeur' : 'mineur';
ex-fr: Un if/else classique, puis la même chose en une ligne avec l'opérateur ternaire.
ex-en: A classic if/else, then the same thing on one line with the ternary operator.
attention-fr: En JavaScript, 0, "", null, undefined et NaN sont « faux » dans une condition ; utilisez === plutôt que == pour comparer sans conversion.
attention-en: In JavaScript, 0, "", null, undefined and NaN are “falsy” in a condition; use === rather than == to compare without conversion.
voir: boucle, type, operateur

@ operateur
cat: langage
nom: Opérateur
nom-en: operator
alias: operator, opérande, +, -, *, /, %, ==, ===, &&, ||, ?., ??, ++, incrément, modulo, affectation
fr: Symbole qui effectue une opération sur des valeurs (les opérandes) : arithmétique (+ - * / %), comparaison (== === < >), logique (&& || !), affectation (= +=).
en: A symbol that performs an operation on values (the operands): arithmetic (+ - * / %), comparison (== === < >), logic (&& || !), assignment (= +=).
ex: js
| 7 % 3
| 5 === '5'
| 5 == '5'
| null ?? 'défaut'
ex-fr: Le reste de 7 ÷ 3 (1) ; égalité stricte (false) ; égalité avec conversion (true) ; valeur par défaut si null (« défaut »).
ex-en: The remainder of 7 ÷ 3 (1); strict equality (false); loose equality (true); default value if null (“défaut”).
voir: condition, variable, type

@ recursion
cat: langage
nom: Récursivité
nom-en: recursion
alias: récursion, récursif, recursive, appel récursif, cas de base, base case, stack overflow, dépassement de pile
fr: Technique où une fonction s'appelle elle-même sur un cas plus petit du même problème, jusqu'à atteindre un cas de base qui s'arrête. Elle convient bien aux structures en arbre.
en: A technique where a function calls itself on a smaller case of the same problem, until reaching a base case that stops. It suits tree-shaped structures well.
ex: js
| function factorielle(n) {
|   if (n <= 1) return 1;
|   return n * factorielle(n - 1);
| }
| factorielle(4)
ex-fr: factorielle(4) = 4 × 3 × 2 × 1 = 24 ; le cas de base est n ≤ 1.
ex-en: factorielle(4) = 4 × 3 × 2 × 1 = 24; the base case is n ≤ 1.
attention-fr: Sans cas de base, ou trop profonde, la récursivité remplit la pile d'appels : l'erreur « stack overflow » (dépassement de pile) arrête le programme.
attention-en: With no base case, or too deep, recursion fills the call stack: the “stack overflow” error stops the program.
voir: fonction, pile, arbre-donnees, boucle
schema: langage-recursion

@ algorithme
cat: langage
nom: Algorithme
nom-en: algorithm
alias: algorithm, algo, pseudo-code, pseudocode, tri, recherche dichotomique, heuristique
fr: Suite finie et précise d'étapes qui résout un problème ou accomplit une tâche. Une recette de cuisine en est un ; en informatique, on en étudie l'exactitude et le coût (temps, mémoire).
en: A finite, precise sequence of steps that solves a problem or performs a task. A cooking recipe is one; in computing, their correctness and cost (time, memory) are studied.
ex: js
| function recherche(tableauTrie, cible) {
|   let bas = 0, haut = tableauTrie.length - 1;
|   while (bas <= haut) {
|     const milieu = Math.floor((bas + haut) / 2);
|     if (tableauTrie[milieu] === cible) return milieu;
|     if (tableauTrie[milieu] < cible) bas = milieu + 1; else haut = milieu - 1;
|   }
|   return -1;
| }
ex-fr: La recherche dichotomique : on coupe l'intervalle en deux à chaque étape, comme git bisect.
ex-en: Binary search: the interval is cut in two at each step, like git bisect.
voir: complexite, boucle, recursion, bisect

@ complexite
cat: langage
nom: Complexité
nom-en: complexity, Big O
alias: big o, o(n), o(1), o(log n), notation grand o, complexity, complexité temporelle, complexité spatiale, performance algorithmique
fr: Manière de mesurer comment le temps (ou la mémoire) d'un algorithme grandit avec la taille n des données, sans tenir compte de la machine. On la note O(n) : O(1) constant, O(log n) très lent à croître, O(n) proportionnel, O(n²) qui explose.
en: A way of measuring how an algorithm's time (or memory) grows with the size n of the data, regardless of the machine. It is written O(n): O(1) constant, O(log n) very slow-growing, O(n) proportional, O(n²) which explodes.
+fr: Chercher dans un tableau non trié coûte O(n) ; dans un tableau trié par dichotomie, O(log n) ; dans une table de hachage, O(1) en moyenne. Le choix de la structure de données fait donc la performance.
+en: Searching an unsorted array costs O(n); a sorted array with binary search, O(log n); a hash table, O(1) on average. The choice of data structure therefore makes the performance.
voir: algorithme, table-de-hachage, boucle, benchmark
schema: langage-complexite

@ pile
cat: langage
nom: Pile
nom-en: stack
alias: stack, lifo, call stack, pile d'appels, push pop, structure de pile, stack trace, trace d'appels
fr: Structure de données où le dernier élément ajouté est le premier retiré (LIFO, « dernier entré, premier sorti »), comme une pile d'assiettes. La pile d'appels d'un programme s'en sert pour suivre les fonctions en cours.
en: A data structure in which the last element added is the first one removed (LIFO, “last in, first out”), like a stack of plates. A program's call stack uses it to track running functions.
+fr: Quand une erreur survient, le message affiche la « trace de pile » : la liste des fonctions appelées, de la plus récente à la plus ancienne. C'est le premier indice pour trouver un bug.
+en: When an error occurs, the message shows the “stack trace”: the list of functions called, from the most recent to the oldest. It is the first clue for finding a bug.
ex: js
| const pile = [];
| pile.push('a');
| pile.push('b');
| pile.pop()
ex-fr: Empiler a puis b ; dépiler renvoie b, le dernier arrivé.
ex-en: Push a then b; popping returns b, the last one in.
voir: file-fifo, recursion, tableau, event-loop
schema: langage-pile

@ objet
cat: langage
nom: Objet
nom-en: object
alias: object, poo, programmation orientée objet, oop, propriété, property, méthode, attribut, this, encapsulation
fr: Ensemble regroupant des données (ses propriétés) et des fonctions qui agissent dessus (ses méthodes). La programmation orientée objet organise un programme en objets qui collaborent, plutôt qu'en une longue suite d'instructions.
en: A bundle grouping data (its properties) and the functions that act on it (its methods). Object-oriented programming organizes a program as collaborating objects, rather than one long sequence of instructions.
