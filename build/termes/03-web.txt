ex-en: Find a button on the page, then change its text when it is clicked.

@ service-worker
cat: web
nom: Service Worker
alias: service workers, sw, worker de service, mode hors ligne, offline, cache offline, intercepter les requêtes
fr: Script JavaScript que le navigateur exécute en arrière-plan, séparément de la page. Placé entre la page et le réseau, il peut intercepter chaque requête et répondre depuis un cache : c'est ce qui permet à un site de marcher hors ligne.
en: A JavaScript script the browser runs in the background, separately from the page. Sitting between the page and the network, it can intercept each request and answer from a cache: this is what lets a site work offline.
+fr: Il n'a pas accès au DOM, fonctionne par événements (install, activate, fetch) et n'est disponible qu'en HTTPS (ou sur localhost). Il permet aussi les notifications push et la synchronisation en arrière-plan.
+en: It has no access to the DOM, works through events (install, activate, fetch) and is only available over HTTPS (or on localhost). It also enables push notifications and background sync.
ex: js
| self.addEventListener('fetch', (evenement) => {
|   evenement.respondWith(
|     caches.match(evenement.request).then((enCache) => enCache || fetch(evenement.request))
|   );
| });
ex-fr: Pour chaque requête : répondre depuis le cache s'il a la réponse, sinon aller sur le réseau.
ex-en: For each request: answer from the cache if it has the response, otherwise go to the network.
attention-fr: Un service worker mis à jour n'est pas actif tout de suite : il attend que les pages ouvertes avec l'ancienne version soient fermées, sauf s'il force son activation.
attention-en: An updated service worker is not active right away: it waits for the pages open with the old version to close, unless it forces its own activation.
voir: sw-js, cache-api, pwa, web-worker, manifest
schema: web-service-worker

attention-en: A sw.js placed in /js/ would only control pages under /js/: it is the most common mistake.
voir: service-worker, cache-api, pwa, manifest

@ cache-api
cat: web
nom: Cache API
nom-fr: API Cache
alias: caches, cache storage, CacheStorage, caches.open, cache.put, cache.match
fr: Interface JavaScript qui range des réponses HTTP complètes dans des caches nommés, chacun associant une requête à sa réponse. Un service worker s'en sert pour resservir des fichiers sans réseau.
en: A JavaScript interface that stores whole HTTP responses in named caches, each pairing a request with its response. A service worker uses it to serve files again without a network.
+fr: On y range ce qu'on veut, quand on veut, et rien n'expire tout seul : c'est au code de supprimer les anciens caches à chaque nouvelle version.
+en: You store what you want, when you want, and nothing expires by itself: it is up to the code to delete old caches with each new version.
ex: js
| const cache = await caches.open('coquille-v1');
| await cache.addAll(['/', '/style.css', '/app.js']);
| const reponse = await caches.match('/style.css');
ex-fr: Ouvrir un cache, y mettre trois fichiers, puis relire l'un d'eux.
ex-en: Open a cache, put three files in it, then read one of them back.
attention-fr: Ne pas confondre avec le cache HTTP du navigateur, géré automatiquement selon les en-têtes des réponses.
attention-en: Not to be confused with the browser's HTTP cache, managed automatically according to the responses' headers.
voir: service-worker, cache-http, localstorage, indexeddb

@ cors
cat: web
nom: CORS
dev: Cross-Origin Resource Sharing
nom-fr: partage de ressources entre origines
alias: cross-origin resource sharing, same-origin policy, politique de même origine, access-control-allow-origin, preflight, requête pré-vol, origine
fr: Mécanisme par lequel un serveur autorise des pages d'un autre site à lire ses réponses. Par défaut, le navigateur bloque cette lecture (politique de même origine) ; le serveur l'autorise avec l'en-tête Access-Control-Allow-Origin.
en: A mechanism by which a server allows pages from another site to read its responses. By default the browser blocks such reads (same-origin policy); the server allows them with the Access-Control-Allow-Origin header.
+fr: Une origine se compose du protocole, du domaine et du port : http://a.org et https://a.org sont deux origines différentes. Pour certaines requêtes, le navigateur envoie d'abord une demande « pré-vol » (OPTIONS).
+en: An origin is made of the protocol, the domain and the port: http://a.org and https://a.org are two different origins. For some requests, the browser first sends a “preflight” request (OPTIONS).
ex: http
| Access-Control-Allow-Origin: https://mon-site.org
| Access-Control-Allow-Methods: GET, POST
ex-fr: Deux en-têtes de réponse : seul mon-site.org peut lire, avec les méthodes GET et POST.
ex-en: Two response headers: only mon-site.org may read, with the GET and POST methods.
attention-fr: Le blocage a lieu dans le navigateur, pas sur le serveur : un script Node ou curl n'est jamais gêné par CORS.
attention-en: The blocking happens in the browser, not on the server: a Node script or curl is never hindered by CORS.
voir: header, http, csp, api
