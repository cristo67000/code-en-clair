@ bit

en: The smallest unit of information in a computer: a digit that is either 0 or 1. Eight bits make a byte; network speeds are measured in bits per second.
+fr: Avec n bits, on représente 2 puissance n valeurs : 8 bits donnent 256 valeurs, 16 bits 65 536, 32 bits environ 4,3 milliards.
+en: With n bits, you can represent 2 to the power n values: 8 bits give 256 values, 16 bits 65,536, 32 bits about 4.3 billion.
attention-fr: Bit (b minuscule) et octet (B majuscule) : 100 Mb/s (mégabits) font environ 12 Mo/s (mégaoctets) au mieux.

@ byte
cat: data
nom: Byte
nom-fr: octet
alias: octet, o, o., bytes, octets, ko, mo, go, kb, mb, gb, kib, mib
fr: Unité d'information de 8 bits, qui peut prendre 256 valeurs différentes (de 0 à 255). C'est l'unité de base pour mesurer une taille de fichier ou de mémoire : un caractère ASCII tient dans un octet.
en: A unit of information of 8 bits, which can take 256 different values (from 0 to 255). It is the base unit for measuring a file or memory size: one ASCII character fits in a byte.
+fr: En français, l'octet s'écrit « o » (Ko, Mo, Go) ; en anglais, le byte s'écrit « B » (KB, MB, GB). Un octet se note souvent en hexadécimal, sur deux chiffres : 00 à FF.
+en: In English, the byte is written “B” (KB, MB, GB); in French it is “o” (octet). A byte is often written in hexadecimal, on two digits: 00 to FF.
ex: js
| const octets = new Uint8Array([72, 105, 33]);
| console.log(octets.length, octets[0]);
| console.log(new TextDecoder().decode(octets));
ex-fr: Un tableau de trois octets : sa longueur, son premier octet (72), puis leur lecture comme texte (« Hi! »).
ex-en: An array of three bytes: its length, its first byte (72), then reading them as text (“Hi!”).
voir: bit, unites-octets, ascii, buffer, blob
schema: data-octet

@ chunk
cat: data
nom: Chunk
nom-fr: morceau, tronçon
alias: chunks, bloc de données, morceau de données, découpage, chunked, transfer-encoding chunked, fragment
fr: Morceau d'un ensemble de données plus grand, traité ou transmis à part. On découpe un gros fichier en chunks pour le lire sans saturer la mémoire, l'envoyer par étapes ou en reprendre le transfert après une coupure.
en: A piece of a larger set of data, processed or transmitted separately. A big file is cut into chunks to read it without exhausting memory, send it in stages or resume its transfer after a break.
+fr: En web, un fichier JavaScript volumineux est aussi découpé en chunks que le navigateur charge au besoin ; et le codage HTTP « chunked » envoie une réponse morceau par morceau sans en connaître la taille totale.
+en: On the web, a large JavaScript bundle is also split into chunks that the browser loads on demand; and the HTTP “chunked” encoding sends a response piece by piece without knowing its total size.
ex: js
| const flux = (await fetch('/gros.bin')).body.getReader();
| let total = 0;
| while (true) {
|   const { done, value } = await flux.read();
|   if (done) break;
|   total += value.length;
| }
ex-fr: Lire une réponse par morceaux successifs (value) et cumuler leur taille, sans jamais tout garder en mémoire.
ex-en: Read a response in successive chunks (value) and add up their sizes, never holding everything in memory.
attention-fr: Un chunk n'a pas de taille fixe par nature : elle dépend de l'outil ou du choix du programmeur.
attention-en: A chunk has no inherently fixed size: it depends on the tool or the programmer's choice.
voir: stream, buffer, paquet, bundler
schema: data-chunk

@ unicode

nom: Unicode
