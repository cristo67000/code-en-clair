# Git et GitHub — première moitié : les notions de base.

@ git
cat: git
nom: Git
alias: gestion de versions, version control, VCS, versionnement
fr: Logiciel de gestion de versions décentralisé : il enregistre l'historique de tous les fichiers d'un projet et permet à plusieurs personnes d'y travailler en parallèle sans s'écraser.
en: A distributed version control system: it records the full history of a project's files and lets several people work on them in parallel without overwriting each other.
+fr: Créé en 2005 par Linus Torvalds pour développer le noyau Linux. Chaque copie d'un projet contient tout son historique, on peut donc travailler sans réseau.
+en: Created in 2005 by Linus Torvalds to develop the Linux kernel. Every copy of a project holds its whole history, so you can work offline.
ex: bash
| git init
| git status
| git --version
ex-fr: Créer un dépôt dans le dossier courant, voir l'état du projet, vérifier que Git est installé.
ex-en: Create a repository in the current folder, see the project's state, check that Git is installed.
attention-fr: Git est l'outil, installé sur votre ordinateur ; GitHub est un service en ligne qui héberge des dépôts Git.
attention-en: Git is the tool, installed on your computer; GitHub is an online service that hosts Git repositories.
voir: github, repository, commit, branch
schema: git-zones

@ github
cat: git
nom: GitHub
alias: gitlab, bitbucket, forge logicielle
fr: Plateforme en ligne qui héberge des dépôts Git et fournit des outils pour collaborer : pull requests, tickets (issues), automatisation (Actions) et sites statiques (Pages).
en: An online platform that hosts Git repositories and provides collaboration tools: pull requests, issue tracking, automation (Actions) and static websites (Pages).
+fr: GitLab et Bitbucket jouent le même rôle. Un dépôt GitHub public est visible de tous ; son historique aussi, y compris les adresses e-mail des auteurs des commits.
+en: GitLab and Bitbucket play the same role. A public GitHub repository is visible to everyone, and so is its history, including the commit authors' email addresses.
ex: bash
| git remote add origin https://github.com/mon-compte/mon-projet.git
| git push -u origin main
ex-fr: Relier le dépôt local à un dépôt GitHub, puis y envoyer la branche main.
ex-en: Link the local repository to a GitHub repository, then send the main branch there.
attention-fr: GitHub n'est pas Git : on peut utiliser Git sans GitHub, et héberger ses dépôts ailleurs.
attention-en: GitHub is not Git: you can use Git without GitHub, and host your repositories elsewhere.
voir: git, remote, pull-request, fork, noreply
schema: git-github

@ repository
cat: git
nom: Repository
nom-fr: dépôt
alias: repo, dépôt, dépôt git, depot
fr: Dossier d'un projet suivi par Git, avec tout son historique de modifications. Un dépôt local vit sur votre ordinateur ; un dépôt distant vit sur un serveur, par exemple GitHub.
en: A project folder tracked by Git, together with its whole history of changes. A local repository lives on your computer; a remote repository lives on a server such as GitHub.
+fr: L'historique est rangé dans le dossier caché .git. Copier ce dossier, c'est copier tout le projet et son passé.
+en: The history is stored in the hidden .git folder. Copying that folder means copying the whole project and its past.
ex: bash
| git init mon-projet
| cd mon-projet
| ls -a
ex-fr: Créer un dépôt dans un nouveau dossier, puis lister ses fichiers, cachés compris : on y voit .git.
ex-en: Create a repository in a new folder, then list its files, hidden ones included: .git shows up.
voir: git, dossier-git, clone, remote
schema: git-remote

@ dossier-git
cat: git
nom: .git
alias: dossier git, git slash, git/, .git/, dossier .git
fr: Dossier caché à la racine d'un projet, créé par git init : il contient tout l'historique, la configuration et l'état du dépôt. Sans lui, le dossier n'est plus un dépôt.
en: A hidden folder at the root of a project, created by git init: it holds the whole history, the configuration and the state of the repository. Without it, the folder is no longer a repository.
+fr: On n'y touche jamais à la main. Les commits, les arbres et les blobs y sont rangés sous forme d'objets identifiés par leur empreinte, dans .git/objects.
+en: You never edit it by hand. Commits, trees and blobs are stored there as objects identified by their hash, in .git/objects.
ex: bash
| ls .git
| cat .git/HEAD
ex-fr: Lister le contenu du dossier, puis lire HEAD pour connaître la branche courante.
ex-en: List the folder's contents, then read HEAD to see the current branch.
attention-fr: Ne pas confondre .git (le dossier) avec .gitignore (le fichier qui liste ce que Git doit ignorer).
attention-en: Not to be confused with .git (the folder) and .gitignore (the file listing what Git should ignore).
voir: repository, gitignore, objet-git, hook
schema: git-dossier-git

@ clone
cat: git
nom: Clone
alias: git clone, cloner
fr: Copie complète d'un dépôt distant sur votre ordinateur : les fichiers, mais aussi tout l'historique. Git relie automatiquement la copie à son origine sous le nom origin.
en: A full copy of a remote repository on your computer: the files, but also the entire history. Git automatically links the copy to its source under the name origin.
+fr: L'option --depth 1 ne récupère que le dernier état (clone superficiel), bien plus rapide sur un gros projet.
+en: The --depth 1 option only fetches the latest state (a shallow clone), much faster on a large project.
ex: bash
| git clone https://github.com/mon-compte/mon-projet.git
| git clone --depth 1 https://github.com/mon-compte/mon-projet.git
ex-fr: Cloner un dépôt entier, ou seulement son dernier état.
ex-en: Clone a whole repository, or just its latest state.
attention-fr: Un clone est indépendant de l'original : ce que vous y faites n'est pas envoyé tant que vous n'avez pas fait un push. Ce n'est pas un fork (copie sur GitHub).
attention-en: A clone is independent of the original: nothing you do reaches it until you push. It is not a fork (a copy on GitHub).
voir: repository, remote, origin, fork, fetch
schema: git-clone

attention-en: A web clone is not a Git clone: it copies what a browser can see, not the project's source code or history.
voir: clone, scraping, html

@ commit
cat: git
nom: Commit
alias: git commit, valider, enregistrer les modifications
fr: Instantané enregistré de l'état du projet à un moment donné, avec un message, un auteur et une date. C'est l'unité de base de l'historique Git.
en: A recorded snapshot of the project's state at a given moment, with a message, an author and a date. It is the basic unit of Git's history.
+fr: Chaque commit reçoit une empreinte unique (son hash) et pointe vers son parent : l'historique est une chaîne de commits. On le crée depuis l'index, avec git commit.
+en: Each commit gets a unique hash and points to its parent: the history is a chain of commits. It is created from the index, with git commit.
ex: bash
| git add index.html
| git commit -m "Ajoute la page d'accueil"
| git log --oneline
ex-fr: Mettre un fichier en attente, l'enregistrer dans un commit, puis relire l'historique en une ligne par commit.
ex-en: Stage a file, record it in a commit, then read the history at one line per commit.
attention-fr: Un commit n'est pas un envoi : il reste sur votre ordinateur tant que vous ne faites pas git push.
attention-en: A commit is not an upload: it stays on your computer until you run git push.
voir: add, index-git, message-de-commit, amend, push, hash
schema: git-commit

@ message-de-commit
cat: git
nom: Message de commit
nom-en: commit message
alias: commit message, conventional commits, feat fix chore
fr: Court texte qui décrit ce que change un commit et pourquoi. Une première ligne d'environ 50 signes, à l'impératif, résume ; une ligne vide puis un paragraphe peuvent détailler.
en: A short text describing what a commit changes and why. A first line of about 50 characters, in the imperative mood, summarizes it; a blank line then a paragraph may add detail.
+fr: La convention « Conventional Commits » préfixe le message par un type : feat pour une fonctionnalité, fix pour une correction, docs, refactor, test, chore. Elle permet de générer automatiquement un journal des changements.
+en: The “Conventional Commits” convention prefixes the message with a type: feat for a feature, fix for a bug fix, docs, refactor, test, chore. It makes it possible to generate a changelog automatically.
ex: bash
| git commit -m "fix: corrige le calcul de la TVA" -m "L'arrondi se faisait avant la somme."
ex-fr: Une première ligne courte, puis un second paragraphe avec le détail.
ex-en: A short first line, then a second paragraph with the details.
voir: commit, amend, log
schema: git-commit

@ branch

nom: Branch
nom-fr: branche
alias: branche, git branch, branching
fr: Ligne d'historique indépendante : un simple pointeur mobile vers un commit. Créer une branche permet de développer une idée sans toucher à la version principale.
en: An independent line of history: simply a movable pointer to a commit. Creating a branch lets you develop an idea without touching the main version.

@ head
cat: git
nom: HEAD
alias: git head, head~1, tête, pointeur courant
fr: Pointeur spécial de Git qui désigne l'endroit où vous vous trouvez : en général la branche courante, donc son dernier commit. Le prochain commit aura HEAD pour parent.
en: A special Git pointer that tells where you are: usually the current branch, and so its latest commit. The next commit will have HEAD as its parent.
+fr: HEAD~1 désigne le parent de HEAD, HEAD~2 son grand-parent. C'est la façon usuelle de dire « avant-dernier commit ».
+en: HEAD~1 designates the parent of HEAD, HEAD~2 its grandparent. It is the usual way to say “the commit before the last”.
ex: bash
| git show HEAD
| git diff HEAD~1
| git reset --soft HEAD~1
ex-fr: Voir le dernier commit, comparer avec l'avant-dernier, défaire le dernier commit en gardant ses modifications.
ex-en: Show the last commit, compare with the one before, undo the last commit while keeping its changes.
voir: branch, detached-head, reset, checkout
schema: git-head

@ detached-head

+en: If you go back to a branch without creating a label, those commits become unreachable (and will eventually be cleaned up). To keep them: git switch -c new-branch.

ex-fr: Se placer sur un ancien commit (HEAD détaché), puis créer une branche pour ne pas perdre le travail fait à cet endroit.
ex-en: Move onto an old commit (detached HEAD), then create a branch so the work done there is not lost.
voir: head, checkout, branch, reflog
