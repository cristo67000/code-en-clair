# Android et mobile.

@ android
cat: mobile
nom: Android
alias: système android, os mobile, api level, niveau d'api, sdk android, aosp, kotlin, art, dalvik
fr: Système d'exploitation mobile de Google, fondé sur le noyau Linux, utilisé par la majorité des téléphones du monde. Ses applications s'écrivent surtout en Kotlin ou en Java, et se distribuent par le Play Store ou par fichier APK.
en: Google's mobile operating system, based on the Linux kernel, used by most of the world's phones. Its apps are written mostly in Kotlin or Java, and distributed through the Play Store or as an APK file.
+fr: Chaque version d'Android correspond à un niveau d'API (Android 14 = niveau 34). Les applications déclarent le niveau minimum qu'elles supportent et celui qu'elles visent.
+en: Each Android version corresponds to an API level (Android 14 = level 34). Apps declare the minimum level they support and the one they target.
voir: apk, aab, play-store, sdk-versions, adb
schema: mobile-webview

@ apk
cat: mobile
nom: APK
dev: Android Package
alias: android package, .apk, fichier apk, installer un apk, dex, classes.dex, apksigner, zipalign
fr: Fichier d'installation d'une application Android : une archive qui contient le code compilé (DEX), les ressources, le manifeste et la signature. On peut l'installer directement sur un appareil, sans passer par un magasin.
en: An Android app's installation file: an archive containing the compiled code (DEX), the resources, the manifest and the signature. It can be installed straight onto a device, without going through a store.
ex: bash
| adb install app-debug.apk
| unzip -l app-debug.apk
ex-fr: Installer un APK sur un téléphone branché, puis lister son contenu (un APK est un fichier zip).
ex-en: Install an APK on a connected phone, then list its contents (an APK is a zip file).
voir: aab, adb, sideload, keystore, gradle
schema: mobile-apk-aab

@ aab
cat: mobile
nom: AAB
dev: Android App Bundle
alias: android app bundle, .aab, app bundle, bundle android, bundletool, bundlerelease
fr: Format de publication des applications sur Google Play : un paquet unique qui contient tout le code et toutes les ressources. Google en tire, à l'installation, un APK sur mesure pour chaque appareil (bonne langue, bonne densité, bon processeur), plus léger qu'un APK universel.
en: The publishing format for apps on Google Play: a single package containing all the code and resources. Google derives from it, at installation, a tailored APK for each device (right language, right density, right processor), lighter than a universal APK.
ex: bash
| ./gradlew bundleRelease
ex-fr: Construire l'AAB de production ; il est ensuite signé avec la clé d'importation puis déposé dans la Play Console.
ex-en: Build the production AAB; it is then signed with the upload key and uploaded to the Play Console.
attention-fr: Un AAB ne s'installe pas directement sur un téléphone : pour un essai local, on utilise un APK.
attention-en: An AAB cannot be installed directly on a phone: for a local test, use an APK.
voir: apk, play-console, play-app-signing, gradle
schema: mobile-apk-aab

@ twa
cat: mobile
nom: TWA
dev: Trusted Web Activity
alias: trusted web activity, pwa android, custom tabs, application web android, bubblewrap, pwabuilder, activité web de confiance
fr: Activité Android qui affiche une PWA en plein écran, sans barre d'adresse, grâce au navigateur Chrome. Le site est vérifié par Digital Asset Links : c'est ce qui permet de publier une PWA sur Google Play comme une application ordinaire.
en: An Android activity that displays a PWA full screen, with no address bar, using the Chrome browser. The site is verified through Digital Asset Links: this is what allows a PWA to be published on Google Play like an ordinary app.
+fr: L'application Android n'est qu'une enveloppe : tout le contenu vient du site, qui se met à jour sans republier l'application. Si la vérification échoue, une barre d'adresse s'affiche en haut.
+en: The Android app is only a wrapper: all the content comes from the site, which updates without republishing the app. If verification fails, an address bar shows at the top.
voir: pwa, assetlinks, bubblewrap, webview, play-console
schema: mobile-twa

@ assetlinks
cat: mobile
nom: assetlinks.json
dev: Digital Asset Links
alias: digital asset links, .well-known, well-known, assetlinks, statement list, relation de confiance, delegate_permission
fr: Fichier JSON placé sur un site à l'adresse /.well-known/assetlinks.json, qui déclare quelle application Android (son identifiant et l'empreinte SHA-256 de sa clé de signature) est autorisée à représenter ce domaine. Il prouve le lien entre le site et l'application.
en: A JSON file placed on a site at /.well-known/assetlinks.json, declaring which Android app (its identifier and its signing key's SHA-256 fingerprint) is allowed to represent that domain. It proves the link between the site and the app.
ex: json
| [{
|   "relation": ["delegate_permission/common.handle_all_urls"],
|   "target": {
|     "namespace": "android_app",
|     "package_name": "io.exemple.codeenclair",
|     "sha256_cert_fingerprints": ["AB:CD:…:12"]
|   }
| }]
ex-fr: Une déclaration : l'application io.exemple.codeenclair, signée par la clé d'empreinte donnée, peut ouvrir les liens du domaine.
ex-en: A declaration: the app io.exemple.codeenclair, signed by the key with the given fingerprint, may open the domain's links.
attention-fr: Le fichier doit se trouver à la racine du domaine, jamais dans un sous-dossier. Avec Play App Signing, il faut y ajouter l'empreinte de la clé de signature de Google, pas seulement celle de la clé d'importation.
attention-en: The file must sit at the domain's root, never in a subfolder. With Play App Signing, Google's signing-key fingerprint must be added to it, not only the upload key's.
voir: twa, empreinte, keystore, play-app-signing
schema: mobile-assetlinks

@ webview
cat: mobile
nom: WebView
alias: android webview, wkwebview, vue web, navigateur intégré, custom tabs, chrome custom tabs
fr: Composant d'une application mobile qui affiche des pages web à l'intérieur de l'application, avec le moteur du navigateur. Beaucoup d'applications hybrides ne sont qu'une WebView autour d'un site.
en: A component of a mobile app that displays web pages inside the app, using the browser's engine. Many hybrid apps are just a WebView around a site.
attention-fr: Une WebView n'est pas une TWA : elle n'a pas les fonctions d'un vrai navigateur (cookies partagés, service worker, mises à jour de sécurité) au même niveau.
attention-en: A WebView is not a TWA: it does not have a real browser's features (shared cookies, service worker, security updates) at the same level.
voir: twa, pwa, navigateur, android
schema: mobile-webview

@ keystore
cat: mobile
nom: Keystore
nom-fr: magasin de clés
alias: magasin de clés, jks, pkcs12, .keystore, keytool, clé d'importation, upload key, clé de signature, signing key, clé de publication
fr: Fichier protégé par mot de passe qui contient les clés privées servant à signer une application Android. Sans sa clé, plus personne ne peut publier de mise à jour de l'application : il faut donc la sauvegarder en lieu sûr et ne jamais la publier.
en: A password-protected file containing the private keys used to sign an Android app. Without its key, nobody can publish an update to the app: it must therefore be backed up safely and never published.
ex: bash
| keytool -genkeypair -v -keystore android.keystore -alias cle -keyalg RSA -keysize 2048 -validity 10000
ex-fr: Créer un magasin de clés avec une clé RSA de 2048 bits valable 10 000 jours ; l'outil demande des mots de passe.
ex-en: Create a keystore with a 2048-bit RSA key valid for 10,000 days; the tool asks for passwords.
attention-fr: Ne jamais versionner un keystore ni ses mots de passe dans Git : ajoutez-le à .gitignore et gardez deux copies chiffrées ailleurs.
attention-en: Never commit a keystore or its passwords to Git: add it to .gitignore and keep two encrypted copies elsewhere.
voir: play-app-signing, signature-numerique, empreinte, secret, apk
schema: mobile-signature

@ play-app-signing
cat: mobile
nom: Play App Signing
alias: signature par google play, app signing key, clé de signature de l'application, upload key, clé d'importation, google signe l'application
fr: Service de Google Play où Google garde la clé qui signe les applications distribuées aux utilisateurs. Le développeur signe ses envois avec une clé d'importation (upload key), qu'il peut faire remplacer en cas de perte, ce qui protège contre le blocage définitif.
en: A Google Play service where Google keeps the key that signs the apps distributed to users. The developer signs their uploads with an upload key, which can be replaced if lost, which protects against permanent lockout.
+fr: Conséquence : l'application installée depuis le Play Store porte la signature de Google, dont l'empreinte est différente de celle de votre clé. C'est cette empreinte-là, lue dans la Play Console, qu'il faut ajouter à assetlinks.json.
+en: Consequence: the app installed from the Play Store carries Google's signature, whose fingerprint differs from your key's. It is that fingerprint, read in the Play Console, that must be added to assetlinks.json.
voir: keystore, assetlinks, aab, play-console
schema: mobile-signature

@ sdk-versions
cat: mobile
nom: minSdk, targetSdk, compileSdk
alias: minsdkversion, targetsdkversion, compilesdkversion, niveau d'api, api level, target api, exigence de niveau d'api
fr: Trois niveaux d'API Android déclarés dans un projet : minSdk, le plus ancien Android sur lequel l'application s'installe ; targetSdk, celui pour lequel elle a été testée et dont elle adopte le comportement ; compileSdk, celui contre lequel on compile.

attention-en: The Play Store requires a recent targetSdk every year for new apps and their updates: a level that is too old blocks publication.

@ bubblewrap
