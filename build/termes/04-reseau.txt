# Réseau et HTTP.

@ http
cat: reseau
nom: HTTP
dev: HyperText Transfer Protocol
alias: protocole http, requête http, http/1.1, http/2, http/3, hypertext transfer protocol, requête réponse, request response
fr: Protocole de communication du web : un client (le navigateur) envoie une requête à un serveur, qui renvoie une réponse. Chaque échange est indépendant des précédents ; le serveur ne se souvient de rien entre deux requêtes.
en: The web's communication protocol: a client (the browser) sends a request to a server, which sends back a response. Each exchange is independent of the previous ones; the server remembers nothing between two requests.
+fr: Une requête porte une méthode (GET, POST…), une adresse et des en-têtes ; la réponse porte un code de statut (200, 404…), des en-têtes et un corps (la page, un JSON, une image).
+en: A request carries a method (GET, POST…), an address and headers; the response carries a status code (200, 404…), headers and a body (the page, JSON, an image).
ex: http
| GET /termes.json HTTP/1.1
| Host: exemple.org
| Accept: application/json
|
| HTTP/1.1 200 OK
| Content-Type: application/json
| Content-Length: 27
ex-fr: Une requête GET en haut, le début de la réponse en bas : statut 200 et type JSON.
ex-en: A GET request at the top, the start of the response below: status 200 and JSON type.
voir: https, methode-http, code-de-statut, header, url
schema: reseau-requete-reponse

@ https
cat: reseau
nom: HTTPS
dev: HTTP Secure
alias: http secure, http sécurisé, cadenas, tls, ssl, certificat https, connexion sécurisée
fr: HTTP à l'intérieur d'un canal chiffré par TLS : personne, sur le chemin, ne peut lire ni modifier les échanges, et le navigateur vérifie que le serveur est bien celui qu'il prétend être, grâce à son certificat.
en: HTTP inside a channel encrypted with TLS: nobody on the way can read or alter the exchanges, and the browser checks that the server really is who it claims to be, thanks to its certificate.
+fr: Il est devenu la norme : les navigateurs signalent les sites en simple HTTP comme « non sécurisés », et les fonctions puissantes (service worker, géolocalisation) exigent HTTPS.
+en: It has become the norm: browsers flag plain-HTTP sites as “not secure”, and powerful features (service worker, geolocation) require HTTPS.
attention-fr: Le cadenas garantit une connexion chiffrée vers le bon domaine, pas que le site soit honnête.
attention-en: The padlock guarantees an encrypted connection to the right domain, not that the site is honest.
voir: http, tls, certificat, service-worker
schema: reseau-tls

@ tls
cat: reseau
nom: TLS
dev: Transport Layer Security
alias: ssl, transport layer security, chiffrement du transport, handshake tls, poignée de main
fr: Protocole qui chiffre et authentifie une communication réseau. Au début, le client et le serveur négocient des algorithmes et échangent des clés (la « poignée de main ») ; ensuite, tout ce qu'ils s'envoient est chiffré.
en: A protocol that encrypts and authenticates a network communication. At the start, the client and the server negotiate algorithms and exchange keys (the “handshake”); afterwards, everything they send each other is encrypted.
+fr: TLS a remplacé SSL, dont le nom reste en usage courant (« certificat SSL »). Les versions actuelles sont TLS 1.2 et 1.3.
+en: TLS replaced SSL, whose name remains in everyday use (“SSL certificate”). The current versions are TLS 1.2 and 1.3.
voir: https, certificat, chiffrement, cle-publique-privee
schema: reseau-tls

@ ip
cat: reseau
nom: IP
dev: Internet Protocol
nom-fr: adresse IP
alias: adresse ip, ipv4, ipv6, internet protocol, 127.0.0.1, adresse réseau
fr: Numéro qui identifie une machine sur un réseau, comme une adresse postale. IPv4 en compte quatre entre 0 et 255 (192.168.1.10) ; IPv6, plus long, en hexadécimal (2001:db8::1), a été créé parce que les adresses IPv4 s'épuisent.
en: A number that identifies a machine on a network, like a postal address. IPv4 has four between 0 and 255 (192.168.1.10); IPv6, longer, in hexadecimal (2001:db8::1), was created because IPv4 addresses are running out.
+fr: Certaines adresses sont privées, valables seulement dans un réseau local (192.168.x.x, 10.x.x.x). 127.0.0.1 désigne toujours la machine elle-même.
+en: Some addresses are private, valid only inside a local network (192.168.x.x, 10.x.x.x). 127.0.0.1 always means the machine itself.
attention-fr: Un serveur web reçoit l'adresse IP de chaque visiteur : c'est une donnée personnelle au sens du droit européen.
attention-en: A web server receives every visitor's IP address: it is personal data under European law.
voir: dns, port, localhost, tcp, paquet

@ dns

en: The Internet's phone book: it translates a readable domain name (example.org) into the IP address (93.184.216.34) that machines actually use. Every browser consults it before contacting a site.
+fr: Les réponses sont gardées en mémoire un certain temps (TTL) : un changement d'adresse met parfois des heures à se propager partout.

@ url
cat: reseau
nom: URL
dev: Uniform Resource Locator
alias: uniform resource locator, uri, adresse web, lien, query string, paramètres d'url, ancre, fragment, hash d'url
fr: Adresse complète d'une ressource sur le web : le protocole, le domaine, un éventuel port, le chemin, puis facultativement des paramètres (?a=1) et une ancre (#section).
en: The full address of a resource on the web: the protocol, the domain, an optional port, the path, then optionally parameters (?a=1) and an anchor (#section).
+fr: L'ancre après # n'est jamais envoyée au serveur : elle reste dans le navigateur. Les caractères spéciaux d'une URL sont encodés en pourcentage (l'espace devient %20).
+en: The anchor after # is never sent to the server: it stays in the browser. Special characters in a URL are percent-encoded (a space becomes %20).
ex: js
| const url = new URL('https://exemple.org:8080/blog/post?lang=fr#commentaires');
| console.log(url.hostname, url.pathname, url.searchParams.get('lang'));
ex-fr: Découper une URL : le domaine, le chemin et la valeur du paramètre lang.
ex-en: Split a URL: the domain, the path and the value of the lang parameter.
attention-fr: Une URL est une adresse qui indique où trouver une ressource ; une URI est le terme plus général pour l'identifier, qu'on sache la localiser ou non.
attention-en: A URL is an address that says where to find a resource; a URI is the more general term to identify it, whether or not it can be located.
voir: domaine, http, dns, slash
schema: reseau-url

@ methode-http

alias: get, post, put, patch, delete, head, options, verbe http, http verb, http methods
fr: Mot qui, dans une requête HTTP, indique l'intention : GET lit une ressource, POST en crée une, PUT la remplace, PATCH la modifie en partie, DELETE la supprime, OPTIONS demande ce qui est permis.

|   headers: { 'Content-Type': 'application/json' },
|   body: JSON.stringify({ texte: 'à retenir' }),
