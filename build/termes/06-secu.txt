# Sécurité et cryptographie.

@ hash
cat: secu
nom: Hash
nom-fr: hachage, valeur de hachage
alias: hachage, haché, fonction de hachage, hash function, digest, condensat, valeur de hachage, hasher, hash d'un commit
fr: Valeur de taille fixe calculée à partir de données par une fonction de hachage. Le même contenu donne toujours le même hash ; changer un seul octet le change entièrement ; et on ne peut pas retrouver les données à partir de lui.
en: A fixed-size value computed from data by a hash function. The same content always gives the same hash; changing a single byte changes it entirely; and you cannot get the data back from it.
+fr: Deux usages : reconnaître ou vérifier un contenu sans le comparer octet par octet (Git identifie chaque commit par son hash), et stocker des mots de passe sans les garder en clair. On dit aussi « empreinte » ou « condensat ».
+en: Two uses: recognizing or verifying content without comparing it byte by byte (Git identifies each commit by its hash), and storing passwords without keeping them in clear. It is also called a “digest” or “fingerprint”.
ex: js
| async function sha256(texte) {
|   const octets = new TextEncoder().encode(texte);
|   const hash = await crypto.subtle.digest('SHA-256', octets);
|   return [...new Uint8Array(hash)].map((o) => o.toString(16).padStart(2, '0')).join('');
| }
| await sha256('Bonjour');
ex-fr: Calculer le SHA-256 de « Bonjour » (9172e8ee…). Avec « bonjour » en minuscule, le résultat est totalement différent (2cb4b143…).
ex-en: Compute the SHA-256 of “Bonjour” (9172e8ee…). With a lowercase “bonjour”, the result is completely different (2cb4b143…).
attention-fr: Un hash n'est pas un chiffrement : on ne peut pas le « déchiffrer ». Il n'est pas non plus une clé de sécurité à lui seul (voir le hachage de mots de passe et le sel).
attention-en: A hash is not encryption: it cannot be “decrypted”. Nor is it a security key by itself (see password hashing and salt).
voir: sha, empreinte, checksum, salage, commit
schema: secu-hash

@ sha
cat: secu
nom: SHA
dev: Secure Hash Algorithm
alias: sha-1, sha1, sha-256, sha256, sha-512, sha-3, secure hash algorithm, sha256sum, shasum
fr: Famille de fonctions de hachage normalisées, dont les plus connues sont SHA-1 (160 bits, 40 chiffres hexadécimaux), SHA-256 (256 bits, 64 chiffres) et SHA-512. SHA-256 est aujourd'hui le choix courant ; SHA-1 n'est plus sûr contre un attaquant.
en: A family of standardized hash functions, the best known being SHA-1 (160 bits, 40 hexadecimal digits), SHA-256 (256 bits, 64 digits) and SHA-512. SHA-256 is today's usual choice; SHA-1 is no longer safe against an attacker.
+fr: Git a longtemps identifié ses objets par SHA-1 (les identifiants de commit sur 40 signes) et migre vers SHA-256. On ne réduit pas un SHA-256 en le tronquant sans perdre de sécurité, mais on peut afficher ses premiers signes, comme le fait Git (3f2a9c1).
+en: Git has long identified its objects with SHA-1 (the 40-character commit ids) and is migrating to SHA-256. Truncating a SHA-256 loses security, but its first characters can be shown, as Git does (3f2a9c1).
ex: bash
| echo -n "abc" | sha256sum
| sha256sum fichier.zip
ex-fr: Le SHA-256 de « abc » est ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad ; la seconde commande vérifie l'intégrité d'un fichier téléchargé.
ex-en: The SHA-256 of “abc” is ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad; the second command checks the integrity of a downloaded file.
attention-fr: SHA-256 est rapide : c'est une qualité pour vérifier un fichier, un défaut pour stocker un mot de passe, où l'on veut une fonction volontairement lente.
attention-en: SHA-256 is fast: a quality for checking a file, a flaw for storing a password, where a deliberately slow function is wanted.
voir: hash, empreinte, commit, salage, checksum
schema: secu-hash

en: The hash of a certificate's or key's content, written in hexadecimal (often in pairs separated by colons). It lets you verify, without comparing the whole certificate, that you have the right key, for example the one that signs an Android app.

@ chiffrement
cat: secu
nom: Chiffrement
nom-en: encryption
alias: encryption, cryptage, déchiffrement, decryption, aes, chiffrement symétrique, symmetric, chiffrement de bout en bout, e2ee
fr: Transformation de données en un texte illisible, à l'aide d'une clé, pour que seule une personne détenant la bonne clé puisse les retrouver. Contrairement au hachage, il est réversible.
en: Transforming data into unreadable text, using a key, so that only someone holding the right key can recover it. Unlike hashing, it is reversible.
+fr: En chiffrement symétrique (AES), la même clé chiffre et déchiffre : elle doit être partagée en secret. En chiffrement asymétrique, deux clés différentes se répondent (clé publique, clé privée).
+en: In symmetric encryption (AES), the same key encrypts and decrypts: it must be shared secretly. In asymmetric encryption, two different keys answer each other (public key, private key).
attention-fr: Ne pas confondre avec le hachage (à sens unique) ni avec l'encodage (réversible par n'importe qui). En français, on dit « chiffrer », et « décrypter » désigne le fait de casser un chiffrement sans la clé.
attention-en: Do not confuse encryption (reversible with a key) with hashing (one-way) or encoding (reversible by anyone).
voir: cle-publique-privee, hash, encodage, tls
schema: secu-chiffrement

@ injection-sql
cat: secu
nom: Injection SQL
nom-en: SQL injection
alias: sql injection, sqli, requête préparée, prepared statement, paramétrée, ' or 1=1, or 1=1
fr: Faille où du texte saisi par l'utilisateur est collé dans une requête SQL et interprété comme du SQL : l'attaquant peut lire ou effacer toute la base. Elle disparaît quand on utilise des requêtes paramétrées.
en: A flaw where text entered by a user is pasted into an SQL query and interpreted as SQL: the attacker can read or wipe the whole database. It disappears when parameterized queries are used.
ex: js
| db.query("SELECT * FROM users WHERE nom = '" + saisie + "'");
| db.query('SELECT * FROM users WHERE nom = ?', [saisie]);
ex-fr: La première ligne concatène la saisie (dangereux : « ' OR '1'='1 » renvoie tout le monde) ; la seconde la passe en paramètre, traitée comme une simple valeur.
ex-en: The first line concatenates the input (dangerous: “' OR '1'='1” returns everybody); the second passes it as a parameter, handled as a mere value.
voir: sql, xss, requete-sql, orm
schema: secu-injection

@ moindre-privilege
cat: secu
nom: Moindre privilège
nom-en: least privilege
alias: least privilege, principe du moindre privilège, polp, permissions minimales, droits minimaux
fr: Principe qui veut qu'une personne, un programme ou une clé n'ait que les droits strictement nécessaires à sa tâche. Si elle est compromise, les dégâts restent limités à ce périmètre.
en: A principle stating that a person, program or key should only have the rights strictly needed for its task. If it is compromised, the damage stays limited to that scope.
+fr: Exemples : une application Android qui ne demande aucune permission, un jeton GitHub limité à un seul dépôt en lecture, un service qui tourne sous un compte sans droits d'administrateur.
+en: Examples: an Android app that asks for no permission, a GitHub token limited to a single repository in read-only mode, a service that runs under an account with no administrator rights.
